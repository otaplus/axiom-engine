# Proyectos de ejemplo

Abre cualquiera de estos archivos desde **Archivo → Abrir proyecto…** en Axiom Engine.

| Archivo | Qué incluye |
| --- | --- |
| `bosque-de-chispas.axiom` | Plataformas, monedas, slimes, pinchos, HUD y meta |
| `cazador-estelar.axiom` | Nave, disparo automático, oleadas de enemigos y puntuación |
| `proyecto-vacio.axiom` | Escena mínima con jugador, cámara y suelo |

Puedes modificarlos a mano o pedirle cambios al Copiloto. Los archivos se generan desde las plantillas del motor con `scripts/e2e.mjs`.
